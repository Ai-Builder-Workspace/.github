## About

We're an independent product studio based in **Ho Chi Minh City, Vietnam**, shipping AI-powered mobile apps, web tools, and exploratory AI hardware. We build things we'd actually use ourselves — utilities that respect your time, games that don't beg for retention, and lab prototypes that put intelligence inside everyday objects.

> No chatbot theater. No "AI" stickers. Just shorter routes from intent to outcome.

## Lab specimens

Things we're prototyping next. Sensors + embedded models + consumer hardware:

- **Earbuds that listen back** — battery, equalizer, listening profile learned on-device · *seed: [BudWave](https://aibuilder.work/apps/budwave.html)*
- **Mirrors that summarize the day** — on-device LLM (llama-3.2 1.3B Q4, ~320ms latency, ~2.1W power)
- **Plant pots with feelings** — soil sensors + microcontroller + a small translation model
- **Doorbells that know your friends** — local vision models, no cloud
